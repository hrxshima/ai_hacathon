# PICK ME AGAIN — интерактивный сайт о циркулярной моде

Кейс РУВИКИ, научная журналистика. Статичный сайт: HTML + CSS + чистый JavaScript, без сборки и зависимостей.

## Запуск
Открыть `index.html` в браузере. Для надёжного автозапуска видео лучше через локальный сервер:
```
python3 serve.py   # затем http://127.0.0.1:8000
```
Локальный сервер поддерживает HTTP Range для воспроизведения видео в Safari. MP4 подготовлен для начала загрузки с первого кадра. Если телефон блокирует автозапуск (например, в режиме энергосбережения), видео запускается кнопкой «Повторить видео» или касанием первого экрана. Для проверки с телефона в той же Wi-Fi-сети: `python3 serve.py --bind 0.0.0.0`, затем открыть локальный IP компьютера с портом 8000.

Публикация — любой статический хостинг (GitHub Pages, Netlify, Vercel): загрузить папку целиком.

## Структура
```
index.html     — разметка: пролог, 4 локации, финал, источники
styles.css     — стили, адаптив (от 320 px), prefers-reduced-motion
script.js      — интерактивы, игра, звук, анимации
article.html   — обновлённая статья «Циркулярная мода» со ссылками на источники
assets/video/       prologue.mp4, first.webp (постер), last.webp (последний кадр)
assets/backgrounds/ fitting, shop, waste, workshop (.webp)
assets/doll/        doll.webp — базовая кукла
assets/clothes/     {pants|tshirt|cardigan|jacket}_{before|repaired|remade}.png
```

## Структура истории
Пролог (видео) → 01 PICK ME! (примерочная) → 02 FOLLOW THE TREND (магазин) → 03 THROW ME AWAY (свалка текстиля) → 04 PICK ME AGAIN (мастерская, игра) → «Не только гардероб» (бизнес и правила ЕС) → 05 THE SECOND LIFE (финал) → источники. Между локациями — фразы-переходы.
Тексты для посетителя — по редакторскому ТЗ v2.

## Мультимедиа
- Видеопролог (8 с, без звука) проигрывается один раз и останавливается на последнем кадре; кнопка «Повторить».
- Звук синтезируется в браузере (Web Audio API), включается кнопкой «Звук»: атмосфера меняется по локациям; швейная машинка, крышка контейнера, щелчки. Аудиофайлов нет.
- Переходы: шторка примерочной, мерцающая лампа магазина, затемнение склада, зелёная лампа мастерской.
- Параллакс фонов, счётчики цифр, схема «линейная / циркулярная», контейнер с раскрывающимися маршрутами, сетка из 100 волокон (≈8% и <1%), полосы 32% / 91%, шкала ЕС с раскрывающимися датами, игра в мастерской со швейной анимацией, слайдер и переключатель «до / после». В мастерской результат остаётся до нажатия «Дальше»; после четырёх решений эта кнопка ведёт к следующей главе.
- Ярлыки Sxx открывают карточку источника по нажатию (работает и на телефоне); полный список — внизу страницы.

## Замена изображений
Одежда накладывается на куклу по координатам в `script.js` (объект `FIT`: left, top, width, height в % от размера куклы и clip для прозрачных полей). При замене файла с другим кадрированием поправьте координаты соответствующего состояния.

## Фактчекинг
Все цифры — из 18 выданных источников (ссылки [S01]–[S18] ведут к списку внизу страницы). Происхождение сведений указано в самих формулировках («по данным H&M», «по прогнозу 2021 года»).
